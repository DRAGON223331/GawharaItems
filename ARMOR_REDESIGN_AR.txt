GawharaItems 1.2.0 — Medieval War Armory

التعديلات:
- إعادة رسم أيقونات الخوذ والصّدريات والبناطيل والأحذية لتظهر كقطع دروع ماينكرافت فعلية وواضحة.
- إضافة 3 أطقم حربية جديدة: Warrior وViking وGladiator، ليصبح الإجمالي 9 أطقم.
- التصميم بقى بطابع حربي قديم: حديد، فولاذ، جلد، برونز، خوذ بواقي وجه ودرع كتف وركب؛ بدون شكل دروع مستقبلية أو Sci‑Fi.
- إضافة سلاح وأداة تعدين مميزين لكل Bundle، بالإضافة إلى War Hammer وHunter Crossbow وBattle Spear.
- تغيير رسمة البيك إكس والفأس العاديين.
- تحديث أيقونات Java وBedrock وخامات الدروع أثناء اللبس وملفات Geyser mappings مع بعض.
- إضافة أمر يعطي كل Bundle منفصلًا مع سلاحه وأداة التعدين الخاصة به: /gitems bundle <player> <set>.

الأطقم المتاحة:
shadow, royal, dragon, demon, ice, angel, warrior, viking, gladiator

تركيب Java:
1) ارفع resourcepack-java-26.3.zip على رابط HTTPS مباشر.
2) تأكد أن قيمة sha1 داخل plugins/GawharaItems/config.yml هي نفس القيمة أعلاه.
3) حدّث JAR الخاص بالبلاجن بعد بنائه باستخدام Java 25.
4) أعد تشغيل السيرفر، ثم وافق على تحميل Resource Pack.
5) اللاعب يقدر يطلب الحزمة مرة أخرى بالأمر /gpack.

تركيب Bedrock عبر Geyser:
1) أوقف السيرفر.
2) احذف نسخ GawharaItems القديمة من plugins/Geyser-Spigot/packs.
3) ضع GawharaItems-Geyser-Bedrock-1.2.0.mcpack داخل packs.
4) استبدل ملف custom mappings بالملف gawharaitems_mappings-1.2.0.json داخل custom_mappings.
5) تأكد أن enable-custom-content: true.
6) أعد تشغيل Geyser والسيرفر بالكامل. لو الأيقونات أو الدروع القديمة ما زالت ظاهرة، امسح Server Resource Pack Cache على جهاز Bedrock ثم ادخل من جديد.

أوامر مهمة:
/gitems list
/gitems give <player> <item_id> [amount]
/gitems bundle <player> <set>
/gitems pack
/gitems reload

ملاحظة بناء:
المشروع يستهدف Paper 26.3 وJava 25. نسخة بيئة العمل الحالية فيها Java 21 فقط، لذلك يلزم بناء JAR من GitHub Actions أو بيئة فيها JDK 25.
