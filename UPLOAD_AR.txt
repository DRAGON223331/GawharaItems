رفع GawharaItems 1.1.2 على GitHub

تنبيه بخصوص Aternos:
Aternos لا يسمح برفع ملفات Java Plugin JAR مخصصة من خارج مكتبته، ولا يوفر وصول FTP أو صلاحية رفع كاملة لملفات الإضافات. لذلك لن تستطيع تثبيت GawharaItems-1.1.2.jar على Aternos بمجرد رفعه. تحتاج استضافة تسمح بإضافات Paper مخصصة مثل exaroton، أو قبول الإضافة في مكتبة Aternos. رفع Resource Pack للـJava مسموح من صفحة Resource Packs، لكنه لا يثبت الإضافة نفسها.

1) فك ضغط GawharaItems-Source-Custom.zip.
2) ارفع محتويات مجلد GawharaItems إلى جذر مستودع GitHub (بحيث يظهر build.gradle في الجذر).
3) افتح Actions وانتظر نجاح Build GawharaItems.
4) حمّل artifact باسم GawharaItems-JAR واستخرج GawharaItems-1.1.2.jar.
5) ارفع JAR إلى plugins في السيرفر وأعد تشغيله بالكامل.

الأوامر:
/gitems
/gitems list
/gitems give <player> <item_id> [amount]
/gitems reload

موديلات Java:
- استخدم مجلد resourcepack-java-26.3 كـ Resource Pack. اضغط محتوياته إلى ZIP مع pack.mcmeta في جذر ZIP ثم ثبّته عند لاعبي Java أو استضفه كرابط HTTPS ليتم فرضه من إعدادات السيرفر.

Geyser / Bedrock:
- تأكد من enable-custom-content: true في إعدادات Geyser.
- على Aternos تأكد أولًا من إمكانية الكتابة داخل مجلدي custom_mappings وpacks الخاصين بـGeyser؛ قد لا توفر لوحة الاستضافة وصولًا كاملًا لهما.
- انسخ geyser-bedrock-pack/gawharaitems_mappings.json إلى مجلد custom_mappings في Geyser.
- اضغط محتويات geyser-bedrock-pack في ملف MCpack بحيث يكون manifest.json في جذر الحزمة، وضعه داخل مجلد packs في Geyser.
- أعد تشغيل Geyser والسيرفر.

مهم: إضافة Paper تعمل للاعبي Java وBedrock، لكن الموديلات المخصصة لعميل Bedrock تتطلب ملفات Geyser المنفصلة. بعض لوحات الاستضافة قد لا تسمح بالوصول إلى مجلدات Geyser؛ يجب التأكد من إمكانية رفع الملفات.


تفعيل تحميل Resource Pack تلقائيًا للاعبي Java (الإصدار 1.1.2):
1) ارفع الملف resourcepack-java-26.3.zip الموجود في جذر المشروع إلى استضافة ملفات تعطي رابط HTTPS مباشرًا (يمكن استخدام GitHub Releases).
2) الرابط المباشر لمستودع DRAGON223331/GawharaItems مضبوط مسبقًا في الإعدادات. بعد رفع النسخة الجديدة إلى main سيشير إلى الحزمة الجديدة.
3) اترك resource-pack.sha1 كما هو إذا رفعت الملف دون تعديل. إذا أعدت ضغط الحزمة، احسب SHA-1 من الملف الجديد واستبدل القيمة.
4) أعد تشغيل السيرفر أو نفّذ /gitems reload. سيظهر طلب تحميل الحزمة عند دخول اللاعب. ويمكن للاعب إعادة طلبها بالأمر /gitems pack.
5) resource-pack.required: false يسمح للاعب بالرفض. غيّرها إلى true لجعل الحزمة مطلوبة.
مهم: البلاجن لا يستطيع إنشاء رابط تنزيل عام من تلقاء نفسه؛ يجب استضافة ملف ZIP على رابط HTTPS مباشر يمكن للاعبين الوصول إليه.


التحديث المرئي 1.1.2: تم تحسين أيقونات السيوف والدروع إلى 64x64، وإعادة رسم خامات الدروع الملبوسة على خريطة UV القياسية 64x32 لكل من Java وBedrock.
