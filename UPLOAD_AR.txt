تثبيت GawharaItems 1.2.0 — نسخة Medieval War Armory

1) بناء إضافة السيرفر (JAR)
- فك ضغط GawharaItems-Source-Custom-1_2_0-Medieval-Edition.zip.
- ارفع محتويات مجلد GawharaItems إلى جذر مستودع GitHub بحيث يظهر build.gradle في الجذر.
- افتح Actions وشغّل Build GawharaItems.
- حمّل Artifact باسم GawharaItems-JAR، ثم ضع ملف JAR الناتج داخل plugins وأعد تشغيل السيرفر.
- البناء يتطلب JDK 25. لا تستخدم JDK 21 لبناء هذه النسخة.

2) Java Resource Pack
- ارفع resourcepack-java-26.3.zip كما هو على رابط HTTPS مباشر.
- قيمة SHA-1 الحالية داخل config.yml:
dfe6e82c11d3950ba8beca7b3c0919352b7a105b
- رابط GitHub Raw مضبوط في config.yml من النسخة السابقة؛ بعد رفع الملف الجديد للمستودع سيشير للرابط نفسه.
- بعد استبدال الملف، أعد تشغيل السيرفر أو استخدم /gitems reload. اللاعبون لازم يقبلوا الحزمة.

3) Bedrock عبر Geyser
- أوقف السيرفر.
- في plugins/Geyser-Spigot/packs احذف حزم GawharaItems القديمة وضع:
  GawharaItems-Geyser-Bedrock-1.2.0.mcpack
- في plugins/Geyser-Spigot/custom_mappings احذف ملف mappings القديم وضع:
  gawharaitems_mappings-1.2.0.json
- تأكد من enable-custom-content: true.
- أعد تشغيل Geyser والسيرفر بالكامل.
- لو Bedrock استمر يعرض الخامات القديمة، امسح Server Resource Pack Cache من إعدادات اللعبة ثم أعد الاتصال.

4) أوامر الإدارة
/gitems list
/gitems give <player> <item_id> [amount]
/gitems bundle <player> <set>
/gitems reload
/gpack

الأطقم المتاحة مع أمر bundle:
shadow, royal, dragon, demon, ice, angel, warrior, viking, gladiator

ملاحظة الاستضافة:
الإضافة نفسها تحتاج Paper Plugin مخصص. بعض الاستضافات المجانية لا تسمح برفع JAR مخصص أو الوصول إلى مجلدات Geyser (packs وcustom_mappings)، حتى لو كان رفع Resource Pack عادي ممكنًا.
